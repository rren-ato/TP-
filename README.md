# TP — Laboratorios

Repositorio **open source** de laboratorios, evaluaciones y material complementario de diferentes cursos.

El objetivo es reunir en un solo lugar los **enunciados, archivos de datos, resoluciones y recursos de apoyo**, permitiendo practicar, comparar soluciones y compartir aportes entre compañeros.

> [!NOTE]
> Este repositorio no busca monetizar ni lucrar con el material compartido.

---

## 📂 Contenido de cada laboratorio

Dependiendo del año y del laboratorio, pueden encontrarse:

* 📄 **Enunciado** — Documento oficial de la evaluación.
* 📁 **Archivos de datos** — Archivos `.txt` utilizados como entrada.
* 💻 **Resolución** — Implementaciones y soluciones de los laboratorios.
* 📝 **Material adicional** — Apuntes, ejemplos, grabaciones u otros recursos.

No todos los laboratorios necesariamente contienen una resolución.

## 🤝 Contribuciones

Si tienes una resolución diferente, una corrección, apuntes o material que pueda ser útil para otros estudiantes, eres bienvenido a contribuir mediante un **Pull Request**.

Las contribuciones pueden incluir:

* Nuevas resoluciones.
* Correcciones de errores.
* Mejoras de documentación.
* Nuevos archivos de prueba.
* Apuntes o material complementario.
* Organización o clasificación del material.

> Se recomienda explicar brevemente los cambios realizados en cada Pull Request.

## ⚠️ Importante

Este repositorio tiene fines **educativos y académicos**.

El material se comparte para practicar, estudiar y facilitar el aprendizaje entre estudiantes. Se recomienda **intentar resolver los laboratorios por cuenta propia antes de consultar las resoluciones**.

Si algún material publicado infringe derechos de autor o no debería estar disponible públicamente, puede solicitarse su revisión o retiro mediante un Issue o Pull Request.
